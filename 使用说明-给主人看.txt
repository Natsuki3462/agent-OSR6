================================================================
  OSR-Control 使用说明（给主人看，不用懂代码）
================================================================

一、这是个什么东西
----------------------------------------------------------------
让电脑直接控制 OSR6 六轴设备，不用手机 App，也不用 DKFunPlayer。

它有两个模式：
  · 模拟器模式 —— 不需要插设备，先熟悉一下、看看动作合不合意
  · 真机模式   —— 真的连上设备动

出厂默认是「模拟器」，安全。想动真机要你自己打开开关。

而且它**不会记住**：这次切了真机，下次打开还是模拟器。
这是故意的 —— 免得"昨天调试切了真机，今天一开机设备自己动了"。
要动真机，每次都点一下，多这一下换安全。

有一个网页界面，双击一个文件就打开，左边控制、右边看效果。


二、第一次用（两步）
----------------------------------------------------------------
1) 装依赖（只做一次）
   在项目文件夹里右键 install.ps1 ->「用 PowerShell 运行」
   等它跑完，最后会显示"完成"。

2) 双击 启动.bat
   会弹出一个黑色小窗口 —— 那个别关，它就是服务本身。
   然后浏览器会自己打开界面。看到界面就成了。

   黑窗口一关，界面和服务一起结束。这是正常的，不是崩溃。


三、界面怎么看（先看这条）
----------------------------------------------------------------
顶上一横条，颜色就是当前状态，不用记别的：

   绿 色  = 模拟模式   只在屏幕里动，不会驱动真实设备
   红 色  = 真机模式   动作会直接作用到真实设备，注意安全
   黄 色  = 急停已锁定 什么都动不了，按右上角「解除急停」
   灰 色  = 服务没连上 上面会写原因（比如"没找到 OSR 设备"）

  急停最优先：哪怕服务断了，只要急停还锁着，就是黄色。
  所以"黄灯没了"不等于"能动了"，得真的解除。

左边 —— 控制台
  · 六根轴的滑杆：拖一下，设备就往那边走（松手才发出去）
  · 预设：潮汐、环游、乱流……点一下就一直跑，再点别的就换
  · 快捷动作：往返 / 抽动 / 画圈 / 波浪（点一下做一遍）
  · 强度、速度：两个滑杆，改完点「应用强度」
  · 上面还有：停止动作、回中位、退出服务

右边 —— 模拟视图
  一台 SR6 的立体模型（就是设备的真实外形），跟着数值一起动。
  可以用鼠标自己看：
    · 按住左键拖动  = 转视角（想从侧面、上面看都行）
    · 滚轮          = 拉近拉远
    · 双击          = 视角回到正面
  · 能收起：点右上角那个「⟩」按钮，或者点视图左边缘那条竖条
  · 切到真机后它就不动了，还会变灰变暗，写着「模拟视图已冻结」
    —— 这是故意的。画面在动而设备没动，比画面不动更容易看错。
    （冻结时仍然可以拖动看角度，只是数值不再跟着设备变）


四、急停按钮（最重要的一个）
----------------------------------------------------------------
界面右上角那个「急停」按钮，和 python estop.py 弹出的小窗口，
是同一个东西，按哪个都算。

    「急停」  ->  点一下  ->  「解除急停」

  · 点一下 = 立刻停。设备马上回到中间位置、停止动作，
    而且不管电脑上的程序（或者 AI）还在发什么指令，全都不理。
    顶上的横条同时变成黄色。
  · 想恢复 = 再点一下。按钮变回「急停」，设备保持静止，
    要重新下指令它才会再动。
  · 键盘 F12 也一样，窗口在后台、你在别的程序里也能按。

  按钮关掉了也没关系，已经"急停"的状态还在；
  重新打开再按一下才能解除。

一句话：不放心的时候，就点它。


五、想连真机
----------------------------------------------------------------
1) 设备开机、电量够
2) 手机 App 里断开设备（它同时只认一个主）
3) 关掉 DKFunPlayer
4) 插 USB 线到电脑
5) 界面上点右上角「切到真机」—— 横条变红就成了

   ★ 怎么确认真的连上了？看左边「状态」卡里那一行「连接」：
       本地模拟              = 现在还是模拟器，没碰硬件
       USB 串口 · COM5       = 连上了，走 USB 线，端口 COM5
       蓝牙 BLE · xx:xx      = 连上了，走蓝牙
       USB 串口 · 未连接     = 没连上（横条会写原因）
     鼠标停在上面能看到更详细的信息（波特率、连了多久）。
     右边模拟视图左下角也有个「链路」小标签，没连上时是红的。

   连不上时，点完「切到真机」下面那个日志框会一行行写：
       切到真机：正在连接 USB 串口…
       系统串口：COM5（像目标设备）
       ✓ 已连上：USB 串口 · COM5 @115200
   或者：
       系统里没看到任何串口 —— 查 USB 线 / 驱动
       10 秒内没连上真机（USB 串口 · 未连接）

   如果写「缺 pyserial」，不是设备的问题，是电脑缺个库：
       在项目文件夹按住 Shift 右键 →「在此处打开 PowerShell」→
       python -m pip install pyserial

   要指定串口（比如自动认错了口）：
       界面上会自己弹出一个小窗口让你选，不用敲命令。
       如果没弹（或者想换一个），点状态卡里「连接」那一行的串口名也能改。
       命令行也可以：python daemon.py --real --port COM5

想切回模拟器：界面上再点一下「切到模拟」
不确定现在是哪种：python config.py --show（真机会明确写「REAL 真机」）

  ★ 串口自己选：点「切到真机」后如果 10 秒还没连上，
    会自动弹出「选择串口」窗口，列出这台电脑上所有串口，
    带「像目标设备」标记的就是最可能的那个。点一下就连。
    列表里没有？在下面输入框自己写（比如 COM7），再点「连接」。


六、日志：出问题时看这里
----------------------------------------------------------------
界面下面那个「日志」框，标题右边有两个小按钮：

  「打开日志」 用记事本打开完整的日志文件，能往上翻、能搜索
  「清理日志」 把日志清空，服务不重启，接着用

  为什么不重启？因为日志是用来查"刚才那一下为什么没动"的。
  为了清日志把服务重启一遍，现场就没了。

日志不会越滚越大：单个文件超过 1MB 就自动把旧的挤成 .1（只留一份）。
连上、断开的记录已经去掉了（原来占了九成多，把有用的信息全埋了）。


七、如果 AI 在控制，界面会暂时"锁住"
----------------------------------------------------------------
这个软件是给 AI（agent）用的。AI 正在控制的时候：

  · 顶栏下面会出现一条黄色提示，写着「AI 正在接管控制」
  · 你拖滑杆、点预设会被拒绝，并告诉你"AI 正在接管"
  · 但「停止」和「回中位」永远能用 —— 你要能随时叫停
  · 「急停」更是永远最高优先级，按下去 AI 的控制权立刻被收回

想自己接管：点那条黄色提示右边的「收回控制」。
AI 超过 60 秒没发指令，也会自动把控制权还给你。


八、常用的几条命令（不打开界面也能用）
----------------------------------------------------------------
  python presets.py --list                      看有哪些动作
  python ctl.py --preset tide                   慢慢的那种（潮汐）
  python ctl.py --preset storm                  六轴乱来（乱流）
  python ctl.py --set "L0=70,L2=30" --ms 800    慢慢移到指定位置
  python ctl.py --seq-file gesture.json         播一段编排好的动作
  python ctl.py --status                        看现在什么状态
  python ctl.py --stop                          停住（服务不关，还能继续用）
  python ctl.py --quit                          全部收工

  强度不够/太猛：在 --preset 后面加 --intensity 1.3（或 0.7）

  注意：这些命令要连同一个服务。如果你是用 启动.bat 打开的界面，
  服务已经在跑了，命令直接用就行 —— 不要再 python daemon.py，
  两个会抢同一个端口。


九、出问题了
----------------------------------------------------------------
「双击 启动.bat 黑窗口一闪就没了」
   -> Python 没装好，或者装的时候没勾 "Add to PATH"。
      重装 Python 3.10 以上版本，装的时候勾上那个勾。

「浏览器打开是空白」
   -> 等两秒刷新一下。还不行就看项目文件夹里的 webui-daemon.log，
      最后几行会写原因。

「右边只显示一个方块小人（简版视图）」
   -> 3D 模型库没加载上，或者这台电脑的浏览器不支持 3D（WebGL）。
      功能完全不受影响，只是画得简陋。想修好：
      看左下角日志里那句"3D 初始化失败"后面的原因；
      如果是文件没了，跑一下 python fetch_vendor.py（要联网）。
      它会显示进度条，中途断了再跑一次会接着下，不用从头来。
      或者直接右键 install.ps1 用 PowerShell 运行，它也会补上。

「横条一直是灰色」
   -> 服务没起来。界面上有个「启动控制服务」按钮，点它。
      或者黑窗口已经关了，重新双击 启动.bat。

「连不上控制服务」
   -> daemon.py / 黑窗口 被关了。重新打开。

「打不开串口」
   -> DKFunPlayer 或者别的播放器占着，关掉它们。
      如果是自动认错了口，等那个「选择串口」窗口弹出来，自己挑一个。

「没弹「选择串口」窗口」
   -> 说明它其实连上了，只是链路状态没刷新；看一眼状态卡「连接」那行。
      想手动换：点那一行的串口名，或者重开界面再点「切到真机」。

「日志框里全是没用的连接记录」
   -> 已经不会了。现在只在出错和状态变化（切模式、接管、急停、换串口）
      的时候才写。真想清空，点日志标题右边的「清理日志」。

「界面一切正常，但设备就是不动」
   -> 先看左边状态卡里的「设备」那一栏。如果是空的（—），说明服务
      手里根本没有设备 —— 通常是之前切过真机、没插设备、又切回来了。
      办法：界面上点「退出服务」，再点「启动控制服务」，就恢复了。
      （这个毛病已经修了，正常切回来自动就好；遇到就是旧进程，重启一下。）

「设备没反应」
   -> 先看横条颜色。黄色就是急停锁着，按「解除急停」。
      不是黄色就 python ctl.py --status，看 "estop" 是不是 true。

「动了但方向怪」
   -> 先用小幅度试：python ctl.py --set "L0=56" --ms 300
      看是往上还是往下，再决定要不要调。

「想要个更稳的」
   -> 插 USB 线比走蓝牙稳，延迟也低。


十、安全提醒
----------------------------------------------------------------
· 第一次动真机，手放开关旁边，别让人或东西卡在行程里
· 幅度先小后大，别一上来就满行程
· 急停随时能用（界面按钮 / F12 / 小窗口），比什么都管用
· 不用的时候关掉设备上的物理开关
